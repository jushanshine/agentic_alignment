# 智能体越界行为研究

研究方向：智能体在完成合理任务的过程中，自主采取不符合用户真实意图、权限边界或行为规范的行动。目标会议 ACL 2027。

## 文件

- `research_notes/研究讨论记录.md`：研究要求、讨论中的问题与回答、当前设想和下一步
- `reports/智能体越界行为研究综述.md`：领域综述（前沿公司、研究机构、学术界）
- `research_notes/智能体越界行为研究综述/`：综述的调研笔记与两轮核实记录
- `research_notes/越界场景素材/scenario_catalog.md`：真实越界场景素材目录
- `research_notes/相关工作细读-障碍绕行方向.md`：10 篇最接近工作的原文细读与新颖度评估
- `research_notes/试点实验设计-障碍归因.md`：障碍归因实验的设计稿与两次修订（研究方向尚未确定）

实验代码、按时间顺序的过程记录和结果不在本仓库，而在工作区的
`experiments/obstacle_attribution/`（`README.md`、`WORKLOG.md`、`RESULTS.md`）。
